## v1.2.4 合集启动优化

- 只修改生成模板、资源封装和安装取消逻辑；制作工具 UI 未改。执行器改用目标机预装的 Framework 4.8，模板约 2.23 MiB，无运行库自解压；Win7 需 SP1 和 4.8，.NET 9 不能代替 Framework。
- 启动不遍历全部资源校验，安装时逐款提取并同一遍计算 SHA-256，拦截同长度损坏；资源不二次压缩，保留去重。
- 合集取消/关闭窗口会停止后续队列并终止当前受控进程树；无法建立管理就阻止启动。MSI 服务可能继续回滚，此时报告待检查并保留资源。
- 首启开发样例由约 5.1–5.3 秒降至 1.2–1.4 秒；测试机为 Win11，未清系统缓存，不代表 Win7/Win10 实机冷启动。重复启动略慢，私有内存增加，详见 [完整记录](runner-startup-optimization.md)。
- 开发阶段仅编译和相关定向检查，用户确认后按 v1.2.4 构建独立发布目录。已有合集需用新模板重新生成才生效。
- 发布前 Release 编译无警告、无错误；使用发布包中的实际程序集完成读取解包 9、进程控制 11、队列与界面 17、导出流程 13、生成封装 4，以及实际 Framework 执行器探针 2 项，共 56 项定向检查。独立导出 EXE 的预览、资源校验及模板副本一致性通过；未运行完整回归或真实第三方安装器。
