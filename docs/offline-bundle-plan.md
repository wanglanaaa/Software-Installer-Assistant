# 离线单文件安装包方案

确认及简化更新日期：2026-10-29。目标：维护软件库和安装方案后，在主界面底部生成一个可复制到其他电脑运行的 EXE，打开后选择方案并一键安装。以简单易用为优先，允许普通安装，不要求所有软件静默安装。

## 产品流程

1. 添加 EXE / MSI。新增页只显示软件名、分类、版本、说明、安装文件、默认目录、关联资源目录、静默参数、联网需求、安装顺序；左侧约 300 像素输入框，右侧帮助说明，十行内容不滚动。
2. 点击「生成单文件安装包」。默认打包当前列表全部软件，当前勾选状态作为默认方案；可仅打包勾选项，并附带其他已保存方案。
3. 检查源文件、关联目录、空间和容量；填写包名称及输出位置。静默参数留空和联网安装器都可正常打包。
4. 生成后复制一个 EXE 到目标电脑，无需安装助理、SDK 或预装 .NET。
5. 打开后选方案、调整勾选、点击一键安装。顺序执行，显示成功、失败、跳过和需要重启，支持日志与失败重试。

## 首版技术设计

- 管理端继续使用 C# / WinForms；新增独立执行器及共用打包/安装库。
- 发布脚本预编译自包含 Windows x64 执行器。管理端直接组合执行器与资源，用户生成时不调用 SDK。
- 文件容器为执行器 + ZIP 资源 + 长度/摘要/版本尾部。使用流式读写，校验 SHA-256，内容相同的资源去重。
- 资源清单只使用内部相对路径；每款软件拥有独立解包目录，关联目录保持原有相对结构。
- 首版以 3500 MiB（约 3.4 GiB）为保守输出上限，超出明确阻止；不宣称支持任意容量单 EXE。大包分卷以后实现。
- 不再要求手动验证静默参数。识别常见 NSIS / Inno 文件特征，自动提供参数；MSI 使用标准命令，尝试只读识别目录属性。未知类型使用普通安装界面。
- 默认目录参数自动识别；无法识别时允许在原安装界面选择。可选手动类型及模板放在右侧，每种类型有说明。
- 静默参数无效并退出后，清空参数最多重试一次普通安装；取消、超时或结果不确定时不自动重开。管理端和导出端共用安装逻辑，不再轮流猜参数或杀死安装窗口。
- 顺序、超时、返回码、检测和依赖等默认后台能力保留，普通用户无需填写高级字段。
- 只有点击安装时才申请管理员权限；首版部署流程以管理员安装为主，不承诺支持所有用户级安装器。
- 取消只停止后续任务；超时或提前返回但检测失败时暂停队列，避免同时运行多个安装器。禁止自动终止未知第三方安装进程。
- 默认不自动重启；仅能通过安装器支持的参数抑制重启。重启续装、全局回滚不在首版承诺范围。
- 已安装检测需要明确规则；无规则的项目显示执行结果，不能声称已经验证实际安装结果。
- 软件库与方案迁移到用户数据目录；旧文件保留，首次读取后保存新副本。

## 验收

- 构建无错误；生成的 EXE 能读取自己的资源并验证摘要。
- 自动检查多方案、去重、关联资源、路径越界拒绝、篡改拒绝、取消和生成失败不覆盖原文件。
- 用无副作用的测试程序验证顺序、失败、重启码、依赖跳过、检测、超时处理。
- 验证 MSI 不填参数、自动识别、未知类型直接普通安装、静默失败切换一次普通安装，以及新增界面在默认/最小尺寸中不溢出。
- 发布版使用自包含执行器；在未安装 .NET 的干净 Windows 虚拟机离线测试，作为对外发布前人工验收项。
