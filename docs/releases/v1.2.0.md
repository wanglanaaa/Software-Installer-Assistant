# v1.2.0 — 单文件安装包与手动配置

发布日期：2026-10-29。

## 新增及改进

- 主界面生成单文件 EXE，包含软件安装源、关联资源、分类和安装方案；在其他 Windows x64 电脑打开即可选择方案安装，无需预装 .NET。
- MSI 自动使用标准安装参数，常见 Inno Setup / NSIS 尝试识别；静默不可用时打开普通安装界面。支持默认安装目录、安装顺序及联网需求标注。
- 新增 / 编辑软件页精简为十项字段，左侧输入、右侧说明；自动填充安装文件名，保留手动修改的名称。
- 新建、加载、保存、另存为单个 JSON 配置，位置自行选择；每次启动为空白，不自动加载旧分类、软件或方案。
- 空分类随配置和安装包保存；切换配置完整替换当前内容。生成向导清空旧检查结果，未勾选时可以直接打包全部。
- 新应用图标用于程序文件、主界面及各窗口标题栏。

## 使用

解压完整的 `SoftwareInstaller-Assistant-v1.2.0-win-x64.zip`，运行其中的 `SoftwareInstaller.UI.exe`。请保留旁边文件及 `Runner` 子目录。

新增软件或手动加载配置，点击「保存配置」选择 JSON 存放位置；选择「生成单文件安装包」并完成配置检查，输出合集 EXE。

旧版 `software_list.json`、`categories.json`、`schemes.json` 可手动导入；导入旧方案后在下拉框选择方案，再保存成新的完整配置。JSON 只记录安装源路径，不包含源文件本体。

## 范围与限制

- 单文件合集上限约 3.4 GiB，启动需先校验及解包；联网安装器仍需要目标电脑联网。
- 第三方安装器的静默、权限、子进程和重启行为需按软件验证。取消或超时不会强制杀死安装进程；结果不确定时暂停队列并保留资源。
- 没有数字签名、重启续装、统一回滚、分卷及 ARM64 支持。发布包不附带任何第三方软件安装源。
