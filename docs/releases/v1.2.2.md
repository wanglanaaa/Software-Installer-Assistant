# v1.2.2 — 软件图标与分类勾选交互

发布日期：2026-11-06。

## 更新内容

- 主列表与分类树中的软件名称前显示安装文件图标；生成的软件合集内嵌各软件图标，移动原安装文件后仍可显示。无法读取图标时显示默认图标。
- 分类名称紧接勾选框显示，不再保留图标空位。
- 必须先创建并选中分类，再添加或拖入软件；选中「所有软件」根节点时不能添加。编辑和批量导入只允许选择已有分类。
- 合集分类筛选旁改为无文字的复选框，支持全选、取消全选和半选状态，逐项勾选时同步更新。只操作当前分类，保留其他分类的选择；选择「全部分类」时控制所有软件。
- 主界面及合集界面加入「本软件由 GitHub 用户 wanglanaaa 制作」说明。
- 更新执行器与界面截图，生成前继续检查执行器版本。

## 使用方法

下载并完整解压 `SoftwareInstaller-Assistant-v1.2.2-win-x64.zip`，运行「软件安装助理.exe」。请保留旁边文件与 `Runner` 子目录，无需预装 .NET。

每次启动后手动加载已有 JSON，或先新建分类再添加软件。已有合集 EXE 需要使用新版重新生成，才能应用此次图标和交互改动。

发布包不附带示例配置或第三方安装文件。界面截图仅用于展示。本次仅提供 ZIP 下载，不附带 SHA256 校验和文件。
