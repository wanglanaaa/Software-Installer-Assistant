# v1.2.3 — 合集运行流畅度与安装停止优化

发布日期：2026-11-07。

## 更新内容

- 合集启动直接读取清单，不再扫描整个资源区进行 SHA-256 校验；解包后也不再读回文件计算 SHA-256。生成时保留资源哈希去重及原有包格式，运行时保留基础格式、长度、清单和路径检查，但无法保证发现同长度的内容损坏。
- 按依赖顺序逐项检查、解包和安装，第一项无需等待全部选中软件解包。已满足检测规则或因前置失败跳过的项目不再解包。
- 解包进度按实际写入的字节计算，限制刷新频率；软件列表分批加载，临时目录在后台清理，减少界面长时间无响应。
- 全选、取消全选和切换方案只同步勾选，保留当前高亮行和滚动位置；复用软件索引与安装顺序，提权后直接恢复待安装选择。
- 「停止…」菜单提供停止后续任务、停止等待并退出、终止当前受管理的 EXE 安装器及子进程。安装中关闭窗口可选择停止等待并退出。
- EXE 安装器先挂起启动，加入进程管理组后再运行；等待受管理的子进程退出后继续队列。超时、中断或结果不确定时停止队列、保留资源与日志，避免误清理和自动重复安装。日志记录安装器 PID、路径和资源目录。

## 使用方法与限制

下载并完整解压 `SoftwareInstaller-Assistant-v1.2.3-win-x64.zip`，运行「软件安装助理.exe」。请保留旁边文件与 `Runner` 子目录，无需预装 .NET。

加载原配置后重新生成「软件集合.exe」，生成的单文件才会包含此次优化；旧合集不会自动更新。发布包不附带用户配置、示例或第三方安装源。本次只提供 ZIP 下载，不附带 SHA256 校验和文件。

强制终止可能留下未完成的安装，需要人工检查或修复。MSI 服务端、服务启动或脱离管理组的进程不保证被覆盖；不支持受控终止时，可停止等待并退出。Windows 7 环境可能无法加入嵌套进程管理组，届时保留资源并提示人工检查。本次未做 Win7 实机或真实第三方安装器的完整验证，不新增平台兼容承诺。

已完成 Release 编译、安装计划与列表交互、逐项资源准备、读取解包、取消和父子进程管理的针对性检查，以及实际导出 EXE 的独立启动、解包和界面渲染验证。
