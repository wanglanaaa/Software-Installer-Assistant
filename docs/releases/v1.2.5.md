# v1.2.5 — 合集默认目录与安装兼容修复

发布日期：2026-11-10。

## 更新内容

- 生成的合集使用各安装包自身默认目录，不再将配置中保存的 D 盘等自定义目录强制传入静默或手动安装器。制作工具直接安装使用的原配置仍保留。
- 修复安装结束后仍等待的问题：继续等待安装子进程，但安装后启动的软件及系统控制台宿主不再单独阻塞后续队列。普通单文件交互程序退出后自动继续；异常返回码仍报告失败。
- 兼容部分绿色自解压外壳创建独立子程序的方式，避免因进程组约束出现“拒绝访问”。补充跟踪独立子进程，取消时结束已跟踪的程序。
- Win7 不再强制创建嵌套进程组，改用父子关系与进程句柄跟踪；其他系统建立管理组失败时也自动切换，不再阻止所有安装。
- 日志明确记录等待主进程、主进程退出及返回码、仍在等待的子进程 PID 和路径。
- 恢复合集执行器内置 .NET 9，无需为合集另装 Framework 或 .NET。保留逐款按需提取、资源同步校验、顺序队列、取消及日志功能。

## 下载与使用

完整解压 `SoftwareInstaller-Assistant-v1.2.5-win-x64.zip`，运行「软件安装助理.exe」，保留旁边文件和 `Runner` 子目录。加载原配置后重新生成合集；旧合集不会自动更新。仅提供便携 ZIP，不附带用户配置、演示数据或第三方安装源。

模板约 109 MiB。相比 v1.2.4 的 Framework 轻量模板，文件体积和首次启动耗时可能增加；没有重新承诺各电脑上的启动秒数。第三方软件自身的运行环境要求不因合集内置运行时而降低。

## 验证与限制

Release 编译无警告、无错误；使用实际发布组件完成 38 项定向检查，覆盖默认目录、交互退出、进程等待与取消、外壳兼容、兼容跟踪模式、模板生成和实际导出 EXE 独立启动。发布截图取自发布组件及实际导出的 EXE。不运行默认完整回归或真实第三方安装程序。

Win7 的父子跟踪分支在 Win11 上强制走同一分支检查，不能替代 Win7 实机验证；.NET 9 官方不支持 Win7，本版不新增系统兼容保证。父子快照可能漏掉采样间隔内退出的中间进程，无 Job 时合集异常退出无法依靠系统自动结束所有后代。MSI 系统服务可能继续回滚，强制取消后需要检查安装状态。

按用户要求跳过发布包 SHA-256 校验和上传后重复下载验证，不提供校验和附件。应用自身提取资源时的完整性检查保留。
